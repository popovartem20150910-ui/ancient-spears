# Ancient Spears 🔱

A standalone Minecraft **1.21.1 Fabric** spear mod, designed to run alongside **Relic Hunt**.

## Plan

- Vanilla-inspired wooden, stone, copper, iron, gold, diamond, and netherite spears
- Jab and charge mechanics
- Lunge enchantment adapted for 1.21.1
- Recipes, item textures, sounds, and balance testing
- Optional special spears in later versions

Work in progress. The repository is separate from `relic-hunt` and uses mod ID `ancient_spears`.

## Русский

**Древние копья** — отдельный мод на Minecraft 1.21.1 Fabric, совместимый с Relic Hunt. Здесь мы постепенно реализуем копья из новых версий, включая атаки и зачарование «Рывок».
